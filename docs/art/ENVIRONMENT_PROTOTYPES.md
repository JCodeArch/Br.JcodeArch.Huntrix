# Original layered environments v1

Card74 authors nine validated palette/stage profiles matching card56 IDs and themes. Original layered sky, distant skyline and near architecture cover daytime urban, nighttime urban, interior and supernatural environments. Day/night urban adds sun/moon and windows; interiors use cabin panels and windows; supernatural uses repeating paired-column arches. Background sorting -30..-19 stays behind gameplay. Bounded12 repeated motifs, no colliders, no lighting/post-processing overrides, explicit camera parallax at .15/.06. Shared grammar is a concept prototype; final landmark-specific painting, HD2D lighting and composition remain production work.

Open ArtBlockout.unity to play the nine-area blockout route with real input, original character rigs, state-driven animation and layered backgrounds. Open ArtVerticalSlice.unity for the explicit card61 airplane slice composition with the same art plus shared Honmoon/Special accepted-event VFX. These are separate snapshots; original gameplay scenes remain owned by their feature. StageArtBridge2D receives assigned standalone controller/builder/player or slice session and camera. It configures explicit prefab/profile mappings, refreshes background after stage transitions, binds current actor accepted-hit effects, and binds slice Honmoon/Special and current boss telegraphs. Soul drain can be assigned via explicit drainer field; this snapshot does not claim automatically binding dynamically-created rescue-beat drainers. Special stage events now trigger the current animator special pose.

Source assets: nine StageEnvironmentDefinition profiles, CharacterArt/rig profiles, procedural renderer code; no external imagery, shaders or textures are copied. Original geometry is a concept/handoff, not approved final film artwork. Final Unity validation must cover all nine traversal scenes, profile contrasts, grayscale separation, switched actors, all10 poses, six VFX, lifecycle teardown, shader availability and rendering performance. User deferred that validation until the final project phase; no runtime pass is claimed.

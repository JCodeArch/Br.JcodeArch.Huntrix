# Gameplay animation prototype

Card72. Three combat-ready playable prefabs and six rival/boss prefabs reuse original physics/attacks unchanged and add the visual rig plus one CharacterGameplayAnimator2D. Rival/boss clones replace the old EnemyPrototypeVisual component with the new rig, preserving their combat controllers and physics. EnemyAgent telegraph/attacking states drive guard/attack presentation; their own HP/death drives collapse. Original prefabs remain unchanged. Explicit CharacterAnimationBinder2D supports manager-bound card69 artwork without changing actor prefabs. Animation transforms are local; physics, invulnerability, hit resolution and timing remain gameplay-owned.

All10 poses are implemented: idle bob, alternating run limbs, raised jump arms, dash lean, attack weapon swing, aerial attack leg tuck, accepted-damage hurt tilt, active-window parry guard, dead-actor collapse, and explicit PlaySpecial raised-arm gesture. Priority death→special→hurt→parry→dash→attack/aerial→jump→run→idle. Dash/attack/parry read real state; hurt subscribes accepted DamageReceived; death reads IsAlive. Zoey uses accepted ShotFired to show a bounded0.3s attack/aerial pose. Special uses an explicit trigger so later effects adapters can bind real stage events. Vertical velocity is a prototype airborne presentation heuristic, not a grounded gameplay decision. No flashing or gameplay animation events authorize damage.

Authored rig timings from card71 drive run/idle cycles and hurt/special presentation durations. Disable unsubscribes and restores the cached visual origin/scale/rotations. Runtime interpolation, camera readability, switch/respawn and performance await final Unity validation. This is an original procedural pose prototype, not finished cel animation.

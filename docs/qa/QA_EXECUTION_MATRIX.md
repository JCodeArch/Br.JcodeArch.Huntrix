# QA execution matrix (#99–104)

All Unity and device cases below are **NOT RUN**. Python evidence-tooling regression tests validate verifier logic only and do not validate gameplay, import or builds. Execute against the same reviewed commit/build hash and retain timestamped logs/screenshots. Record owner, device/OS, setup, steps, expected/actual, severity, status and artifact path for each case. Pending, skipped or unavailable evidence cannot be counted as pass.

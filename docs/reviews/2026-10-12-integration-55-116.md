## Corrected findings re-inspected

- Independent enemy/arena cleanup relinquishes ownership before callback-producing Stop/return operations. Spawn revalidates source, target and lifetime after binding and performance callbacks.
- Stage entry validates the owned actor/attempt before cancellation and commits without transition callbacks. Natural beat advancement waits for attack/cooldown readiness; callback cancellation cannot report successful initialization.
- Checkpoints avoid repeated activation events every frame; action and retarget loops revalidate the active actor after callbacks.
- Food pickup and rescue callbacks cannot continue using a session cleared by Stop. Crisis demonstration accepts an already equal resource value, validates a real crisis and modifies its actual bounded horde.
- Parachute completion requires grounded contact in the landing zone; a separate below-zone/nonfinite reset prevents infinite falling beside the floor.
- Incomplete playtest observation resumes on re-enable; completed records remain explicit one-shot summaries and default human ratings are unset.
- Zoey accepted shots and enemy agent state drive animation. Actual Special events invoke the animator; art bridge shutdown removes effect subscriptions and restores fallback presentation.
- Dynamic audio notices performance finish/cancel without waiting for another score event; crowd gain follows master volume. Final boss stores the accepted outcome before callbacks and reconciles a missed event; scene-owned presentation survives defeated actor teardown.
- Required narrative policy remains required after the Unity object is destroyed, preventing raw text/voice fallback. Modal options hide and pause story UI without cancelling its sequence.
- Age modifiers validate finite products; scaled telegraph/recovery is capped at a documented 60 seconds. Cached previous-character assistance is cleared on switch; real fan-loss input drives dynamic assistance.
- Remapping rejects nonexistent/non-ASCII keys; disabled/destroyed preference sources restore physical defaults. Touch toggles clear when preference mode disappears; settings/comment entry cannot trigger underlying gameplay controls.
- Ground enemy pooling retains and clears protection while inactive, rejects reset during accepted impact notifications and initializes caches before first Awake. Unsupported prefabs retain the prior bounded horde path. Return rejects callback-reactivated objects; nested VFX caches survive enemy leases and honor actual age/reduced-flash context.
- Actual slice ring effects now apply explicit age/flash policy, clear prior effects across actor/profile transitions and preserve a gentle steady essential telegraph.
- Version validators use ASCII SemVer and reject invalid prerelease segments. Build evidence validates artifact root, digest, target, scene paths, exact clean source commit and build GUID. Test XML provenance binds digest/commit; device capture is associated with the built GUID, scenario and nonunique hardware metadata. RC checks reviewed tier assignments and strict numeric budgets, rejecting boolean values masquerading as measurements.

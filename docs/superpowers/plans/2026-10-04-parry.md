# Parry Implementation Plan

> **For agentic execution:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this plan task-by-task. Steps use checkbox syntax.

**Goal:** Implement an explicit parry window in existing combat resolution, then document and commit the card as one unit.

**Architecture:** A static parry definition carries authored duration. A runtime controller owns the window. Damage receiver resolves validated contacts into rejected, parried, or damaged outcomes before mutation. Attack hitbox deduplicates both parry and damage per activation and emits distinct internal/public event paths. Existing impact and hit-stop behavior remains damage-only.

**Tech Stack:** Unity 6, C#, NUnit EditMode/PlayMode tests.

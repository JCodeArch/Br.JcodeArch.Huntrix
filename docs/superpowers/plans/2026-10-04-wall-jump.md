# Wall Jump Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Add configurable wall-jump behavior to the existing 2D jump controller.

**Architecture:** JumpController2D remains the single authority for ground jump, coyote time, buffer and jump cut. A contact provider sends an outward wall normal; the same Jump action launches an unused wall jump while airborne, before falling back to coyote jump. Air dash suppression remains authoritative.

**Tech Stack:** Unity 6, C#, Unity Test Framework PlayMode.

**Spec:** docs/superpowers/specs/2026-10-04-wall-jump-design.md

## Global Constraints
- Add no contact sensor, hardware binding, scene wiring, wall cling, cooldown, events, animation, VFX or SFX.
- Reuse PressJump, ReleaseJump, jumpVelocity, the existing jump cut, and air-dash suppression.
- Require finite, positive wallJumpHorizontalSpeed; invent no numeric default.
- A wall contact supplies an outward normal. Only finite normals with abs(x) > abs(y) qualify.
- One wall jump per continuous valid contact; only explicit contact loss re-arms it.
- Grounded jump retains priority. Airborne wall contact takes priority over coyote; existing coyote/buffer behavior is unchanged without an available wall contact.
- Do not acquire HorizontalMovement2D's owner-scoped dash override. Horizontal input may steer starting next FixedUpdate.

## Review Focus
- Wall normal sign and contact freshness: launch away from left/right walls and reject floor/ceiling or invalid normals.
- Eligibility order: grounded jump, airborne wall jump, then coyote jump; preserve buffer behavior when no jump is eligible.
- Continuous contact: reject repeats until loss and a fresh contact; changing side alone does not re-arm.
- Jump cut and air-dash suppression: cut the wall jump through the shared path and never defer a press past dash suppression.
- Tuning failure: reject zero, negative, NaN and infinite horizontal speed without mutating velocity/contact usage.
